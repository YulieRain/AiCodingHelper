## 数据结构与算法

### 数组相关

#### 1. 两数之和
**题目**：给定一个整数数组 nums 和一个目标值 target，请你在该数组中找出和为目标值的那两个整数，并返回它们的数组下标。

**示例**：
```python
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9，返回 [0, 1]
```

**解法**：
```python
def two_sum(nums, target):
    # 使用字典存储已遍历的数字和索引
    num_map = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in num_map:
            return [num_map[complement], i]
        num_map[num] = i
    return []
```

#### 2. 买卖股票的最佳时机
**题目**：给定一个数组，它的第 i 个元素是一支给定第 i 天的股票价格。如果你最多只允许完成一笔交易（即买入和卖出一支股票），设计一个算法来计算你所能获取的最大利润。

**解法**：
```python
def max_profit(prices):
    if not prices:
        return 0

    min_price = prices[0]  # 记录最低价格
    max_profit = 0          # 记录最大利润

    for price in prices:
        min_price = min(min_price, price)
        max_profit = max(max_profit, price - min_price)

    return max_profit
```

#### 3. 三数之和
**题目**：给你一个包含 n 个整数的数组 nums，判断 nums 中是否存在三个元素 a，b，c，使得 a + b + c = 0？找出所有满足条件且不重复的三元组。

**解法**：
```python
def three_sum(nums):
    nums.sort()
    result = []

    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue  # 跳过重复

        left, right = i + 1, len(nums) - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total == 0:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                left += 1
                right -= 1
            elif total < 0:
                left += 1
            else:
                right -= 1

    return result
```

### 链表相关

#### 1. 反转链表
**题目**：反转一个单链表。

**示例**：
```
输入: 1->2->3->4->5->NULL
输出: 5->4->3->2->1->NULL
```

**解法**：
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverse_list(head):
    prev = None
    current = head

    while current:
        next_node = current.next
        current.next = prev
        prev = current
        current = next_node

    return prev
```

#### 2. 合并两个有序链表
**题目**：将两个升序链表合并为一个新的升序链表并返回。

**解法**：
```python
def merge_two_lists(l1, l2):
    dummy = ListNode()
    current = dummy

    while l1 and l2:
        if l1.val < l2.val:
            current.next = l1
            l1 = l1.next
        else:
            current.next = l2
            l2 = l2.next
        current = current.next

    current.next = l1 if l1 else l2
    return dummy.next
```

### 树相关

#### 1. 二叉树的层序遍历
**题目**：给定一个二叉树，返回其节点值的层序遍历。

**解法**：
```python
from collections import deque

def level_order(root):
    if not root:
        return []

    result = []
    queue = deque([root])

    while queue:
        level_size = len(queue)
        current_level = []

        for _ in range(level_size):
            node = queue.popleft()
            current_level.append(node.val)

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

        result.append(current_level)

    return result
```

#### 2. 验证二叉搜索树
**题目**：给定一个二叉树，判断其是否是一个有效的二叉搜索树。

**解法**：
```python
def is_valid_bst(root):
    def validate(node, low=float('-inf'), high=float('inf')):
        if not node:
            return True
        if not (low < node.val < high):
            return False
        return (validate(node.left, low, node.val) and
                validate(node.right, node.val, high))

    return validate(root)
```

### 设计LRU缓存
**要求**：实现 LRU（最近最少使用）缓存，支持 get 和 put 操作。

**解法**：
```python
class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)
```

### SQL 面试题

#### 1. 找出薪资超过平均工资的员工
**题目**：查询出所有薪资高于公司平均薪资的员工。

**SQL 解法**：
```sql
SELECT *
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);
```

#### 2. 查找重复的电子邮件
**题目**：编写一个 SQL 查询，找出所有重复的电子邮件地址。

**SQL 解法**：
```sql
SELECT email
FROM users
GROUP BY email
HAVING COUNT(*) > 1;
```

#### 3. 计算每月销量
**题目**：查询每个月的销售总量。

**SQL 解法**：
```sql
SELECT
    DATE_FORMAT(order_date, '%Y-%m') AS month,
    SUM(quantity) AS total_quantity
FROM orders
GROUP BY DATE_FORMAT(order_date, '%Y-%m')
ORDER BY month;
```

## Python 面试题

### Python 基础

#### 1. 列表推导式和生成器表达式的区别
- **列表推导式**：返回列表，内存占用大
- **生成器表达式**：返回生成器，内存占用小，适合大数据

```python
# 列表推导式
list_data = [x**2 for x in range(1000000)]  # 占用大量内存

# 生成器表达式
gen_data = (x**2 for x in range(1000000))    # 惰性求值，内存占用小
```

#### 2. Python 的 GIL（全局解释器锁）
- GIL 是 Python 的线程安全机制
- 同一时间只能有一个线程执行 Python 字节码
- 多线程在 CPU 密集型任务中效果不明显
- I/O 密集型任务可以使用多线程

#### 3. 装饰器
```python
def decorator(func):
    def wrapper(*args, **kwargs):
        print("执行前")
        result = func(*args, **kwargs)
        print("执行后")
        return result
    return wrapper

@decorator
def say_hello():
    print("Hello World!")
```

## 数据库面试题

### MySQL

#### 1. 索引的作用
- 提高查询速度
- 保证数据的唯一性
- 加速表与表之间的连接
- 在分组、排序时，减少分组和排序的数据量

#### 2. 事务的四大特性（ACID）
- **原子性**（Atomicity）：事务要么全部完成，要么全部不完成
- **一致性**（Consistency）：事务执行前后数据完整性一致
- **隔离性**（Isolation）：并发执行的事务相互隔离
- **持久性**（Durability）：事务提交后永久生效

#### 3. MVCC（多版本并发控制）
- 乐观锁：读取数据时不加锁，更新时检查是否被修改
- 实现原理：通过 undo log 保存数据的历史版本

#### 1. Redis 数据类型

#### 2. 缓存穿透、缓存击穿、缓存雪崩
- **缓存穿透**：查询不存在的数据，请求直接打到数据库
  - 解决：布隆过滤器、缓存空对象

- **缓存击穿**：热点数据过期，大量请求同时查询数据库
  - 解决：互斥锁、逻辑过期

- **缓存雪崩**：大量缓存同时过期
  - 解决：随机过期时间、高可用架构

#### 3. Redis 持久化
- **RDB**：定期快照，占用空间小，恢复慢
